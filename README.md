# Маяк — застосунок-будильник для Android

Компаньйон Telegram-бота [@MayakAssistant_bot](https://t.me/MayakAssistant_bot).
Тут лише готові збірки; сам застосунок написаний мовою
[NyxilumLang](https://github.com/Faneraiy14/NyxilumLang) і скомпільований у
машинний код ARM64.

## Що робить

Забирає будильники й таймери, які ти ставиш у боті, і ставить їх у
**вбудований «Годинник» телефона**. Дзвонить сам «Годинник» — гучно, поверх
блокування, крізь «Не турбувати» й навіть без інтернету в момент дзвінка.

Не читає повідомлення, контакти чи файли. Власного екрана поки немає —
працює непомітно у фоні.

## Як встановити

1. Скачай `mayak.apk` з [останнього релізу](../../releases/latest)
   (Android спитає дозвіл на встановлення з цього джерела).
2. Відкрий застосунок один раз.
3. У боті: `/app` → «🔗 Підключити цей телефон» — на цьому ж телефоні.
4. Порада: Налаштування → Застосунки → Маяк → Батарея → «Без обмежень».

## Обмеження

- Android не дає застосункам видаляти будильники з «Годинника»: видалений у
  боті будильник вимкни в «Годиннику» сам (телефон нагадає сповіщенням).
- Фоном телефон перевіряє бота раз на ~15 хв; миттєво — кнопкою
  «📱 На телефон» під будильником чи таймером у боті.
- Лише Android (ARM64).

⚠️ Не покладайся лише на це: для важливого перевір, що будильник справді
з'явився в «Годиннику».
